# Python Testing

- Run the smallest relevant test command before changing code.
- Read the failing test and the implementation it exercises.
- Change application code unless the task explicitly requires a test change.
- Re-run the focused test, then run the wider suite when practical.
- Use the configured Python interpreter with `-B`.
